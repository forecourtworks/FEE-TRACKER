# Fee Tracker App

A lightweight web application designed to track school fees across multiple children's tabs with support for local storage persistence, record editing/deleting, and optimized web-to-PDF rendering.

## Features
- **Multi-Child Tabs:** Switch between different children seamlessly.
- **CRUD Operations:** Easily add, edit, and delete fee entries.
- **Local Persistence:** Data is stored locally via `localStorage`.
- **Print & PDF Optimization:** Custom print rules ensure clean layouts, repeating table headers, proper margins, and automatic exclusion of forms during export.
